## 🚀 Download & Run

This is a standalone application. **No installation needed.**

1.  Go to the **[Latest Release](https://github.com/your-username/your-repo/releases)** page.
2.  Download the `bat2exe.exe` file.
3.  Run the file and you're ready to go!

---

## 💡 How to Use

1.  **Select Script:** Click the first `Browse...` button to choose your `.bat` or `.cmd` file.
2.  **(Optional) Name your EXE:** Enter a custom name for your final executable.
3.  **(Optional) Add an Icon:** Click the second `Browse Icon...` button to select a `.ico` file.
4.  **(Optional) Hide Console:** Check the box if you want your script to run silently without a black command window.
5.  **Click Convert!** Your new `.exe` will be created in a `dist` folder right next to the application.
